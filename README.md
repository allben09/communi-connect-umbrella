## 🔍 Overview

**COMMUNI-CONNECT UMBRELLA** is a non-profit umbrella organization that connects, supports, and strengthens **NPOs, NGOs, CO-POs and NPCs** across South Africa – especially in **rural and under-resourced communities**.

This platform serves as the **digital backbone** for the umbrella network, enabling:

| Capability | Description |
| :--- | :--- |
| 🌐 **Organization Showcase** | Member directory with filtering, search, and profile pages |
| 💚 **Donation Portal** | Transparent, secure, international-friendly donation system |
| 📊 **Impact Analytics** | Real-time metrics and reporting for stakeholders |
| 🔐 **Admin Management** | Full CRUD via Django Admin for non-technical staff |
| 🌍 **Multi-Province Support** | All 9 South African provinces with category tagging |
| 📱 **Mobile-First Design** | Fully responsive across all devices |
