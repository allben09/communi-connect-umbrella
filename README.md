## 🔍 Overview

**COMMUNI-CONNECT UMBRELLA** is a non-profit umbrella organization that supports, connects, and strengthens NPOs, NGOs, and NPCs across South Africa – especially in rural and under-resourced communities.

This website was built to:
- 🌐 **Showcase member organizations** under the umbrella
- 💚 **Attract international donors** through a transparent donation portal
- 📢 **Communicate the vision, mission, and 4 programme pillars**
- 🛠️ **Give administrators a full admin panel** to manage members

## 🏛️ 4 Programme Pillars

1. **Organisational Capacity & Compliance Support** – Registration, governance, financial systems, workshops, funder-readiness.
2. **GBV Prevention & Positive Masculinity** – Awareness, prevention campaigns, and supporting survivors.
3. **Youth, Skills & Community Agriculture Programmes** – Skills development, mentorship, food security.
4. **Digital Networking, Resource-Sharing & Partnerships** – Networking platforms, resource hub, funding facilitation.

---

## 🛠️ Tech Stack

- **Backend:** Django 4.2, Python 3.11
- **Frontend:** Bootstrap 5, Custom CSS3, Vanilla JavaScript
- **Animations:** IntersectionObserver scroll reveals + animated counters
- **Database:** SQLite (dev) / PostgreSQL (prod)
- **Deployment:** Render / PythonAnywhere
